# 💻 Aditya Computer - My First Website

Welcome to **Aditya Computer** – my very first web development project! This is a simple, responsive website for a fictional/local computer shop, built entirely using **HTML** and **CSS**.

## 🚀 Project Highlights

- ✅ Fully responsive design (works smoothly on mobile devices)
- ✅ Clean navigation menu for easy browsing
- ✅ Simple layout showcasing a computer shop interface
- ✅ Built with beginner-friendly code and structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Design Techniques (Media Queries)

## 📱 Mobile Friendly

This website adapts to different screen sizes, offering a clean and usable experience whether you're browsing on a desktop or a smartphone.
